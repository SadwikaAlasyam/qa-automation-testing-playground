# QA Automation Testing Playground

A full-stack practice environment created by Sadwika Alasyam for meaningful QA and automation testing.

## What you can test

- Stable and dynamic web locators
- Forms, alerts, popups, nested iframes, scrolling, and asynchronous states
- Sortable, filterable, and paginated tables
- Drag-and-drop, mouse actions, keyboard combinations, and editable controls
- Authentication, sessions, cookies, local storage, and role-based permissions
- REST and SOAP API behavior, error responses, headers, parameters, and schemas
- Database relationships, constraints, validation, and cleanup
- Accessibility, visual regression, retry logic, concurrency, and performance thresholds

## Main areas

- `/qa-lab` — guided business-focused test scenarios
- `/advanced-qa` — advanced automation suites
- `/advanced-qa/auth` — registration, login, session, and authorization practice

## Run locally

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Technology

Vinext, React, TypeScript, Cloudflare Workers, D1, Drizzle ORM, HTML, and CSS.
